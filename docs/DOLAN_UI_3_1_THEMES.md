# DOLAN UI 3.1 — perfiles visuales

Perfiles disponibles: Enterprise Classic, DOLAN Graphite, Liquid Glass Dark, Liquid Glass Light y DOLAN Minimal. Un perfil define superficies, radios, bordes y sombras; no reemplaza la selección de modo claro/oscuro, paleta, iconos, tamaño, densidad ni distribución.

La configuración global vive en Ajustes → DOLAN UI. La preferencia personal está en Ajustes → Configuración de pantalla. El selector superior permite probar perfil y otros parámetros en la sesión actual; «Restablecer» vuelve a preferencias guardadas.

Instalaciones nuevas comienzan en Enterprise Classic. En una actualización, las preferencias existentes se migran al perfil `legacy` para conservar el aspecto anterior. El usuario puede elegir un perfil nuevo cuando quiera.
