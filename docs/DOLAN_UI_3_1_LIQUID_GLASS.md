# DOLAN UI 3.1 — Liquid Glass

El modo `glass` aplica transparencia y blur a POS/encabezados de panel de Mi Espacio, selector flotante y diálogo de carpetas. Las tarjetas internas usan color translúcido sin blur individual. `prefers-reduced-transparency` y `prefers-reduced-motion` desactivan el blur. Los perfiles Liquid Glass mantienen fallback legible con superficies opacas cuando el navegador no soporta `backdrop-filter`.

Probar en desktop y móvil, con tema claro/oscuro, Ocean/Violet/Empresa y contraste alto; revisar uso de GPU y legibilidad antes de usar Glass en cientos de elementos.
